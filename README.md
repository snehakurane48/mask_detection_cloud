
# Face Mask Detection

## Overview
A machine learning project for detecting face masks in images and video streams using computer vision techniques.

## Features
- Real-time face mask detection
- Support for image and video input
- High accuracy classification model
- Easy-to-use interface

## Requirements
- Python 3.7+
- OpenCV
- TensorFlow/Keras
- NumPy

## Installation
```bash
pip install opencv-python tensorflow numpy
```

## Usage
```python
python detect_mask.py --input path/to/image.jpg
```

## Model
The model is trained using a CNN architecture to classify faces as:
- With mask
- Without mask
- Improper mask

## Results
Achieves 95%+ accuracy on test dataset.
